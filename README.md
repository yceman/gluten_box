# gluten_box
Agriculture production culture.  
  
O glúten é um composto de proteínas de armazenamento denominadas prolaminas e glutaminas, que se unem com o amido no endosperma das sementes de vários cereais da família das gramíneas, subfamília Pooideae, principalmente das espécies da tribo Triticeae, como o trigo, cevada, triticale e centeio.
